# Manipulation 工程配套教材

这套教材与 `/home/ww/manipulation_ws` 中的可运行代码一一对应。目标不是把 MoveIt
重新实现成一个产品，而是把黑箱拆成可计算、可测试、可替换的教学模块，再说明工程中
为何仍调用成熟的 MoveIt/OMPL、ros2_control 和 Gazebo 适配器。

建议按以下顺序学习：

若更希望直接理解成熟实现，请先打开[本地成熟源码阅读路线](../guide/MoveIt源码阅读.md)。
每个主题按“本章核心原理 → 当前配置 → MoveIt/OMPL 对应实现 → 观察与验证”学习；
教学简化代码只用于手算和小实验，不必先逐行读完再进入成熟库。

代码地图：

| 数学模块 | 教学实现 | 产品工程中的对应物 |
|---|---|---|
| DH/FK/Jacobian | `manipulation_core/dh_chain.*` | URDF/KDL/MoveIt RobotModel |
| 数值 IK | `inverse_kinematics.*` | KDL、BioIK、TRAC-IK 等插件 |
| 状态/边检测 | `collision_checker.hpp` | MoveIt PlanningScene/FCL |
| RRT / RRT-Connect / RRT* | `sampling_planners.*`、`rrt_connect.*` | OMPL 同名算法族 |
| PRM 路网 | `sampling_planners.*` | OMPL PRM/PRM*/LazyPRM* |
| 路径检查/shortcut | `planning_utils.*` | OMPL motion validator/path simplifier |
| 五次时间缩放 | `trajectory.*` | MoveIt 时间参数化适配器 |
| 重力补偿 | `dynamics.*` | libfranka/Pinocchio/厂家模型 |
| 关节 PID | `pid_controller.*` | ros2_control 控制器或机器人内环 |

边界必须牢记：教学实现的作用是看懂和验证公式，不承担真实机器人安全。真实 FR3 控制
必须使用 Franka 公布并支持的接口、实时条件和安全约束。

阅读建议：首次学习时不要跳过第 0 章。教材中的复杂表达统一采用“公式、符号含义、这一步
在算什么”的顺序；若预览器没有渲染数学块，仍可直接阅读公式后的中文解释。
