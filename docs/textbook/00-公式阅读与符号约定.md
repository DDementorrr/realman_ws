# 公式阅读与符号约定

这份速查表解决两个阅读问题：一是公式中的上标、下标到底在说明什么；二是看到一个公式时，
应该先理解哪一部分。后续各章统一使用本页记号。

## 1. 先看字母，再看角标

教材中的粗体大写字母表示矩阵，粗体小写字母表示向量，普通斜体字母表示标量：

| 写法 | 含义 | 示例读法 |
|---|---|---|
| $\mathbf{T}$ | 4×4 齐次变换矩阵 | “一个坐标变换” |
| $\mathbf{R}$ | 3×3 旋转矩阵 | “一个姿态旋转” |
| $\mathbf{p}$ | 三维位置向量 | “一个点的位置” |
| $\mathbf{q}$ | 全部关节变量组成的向量 | “机器人当前关节状态” |
| $q_i$ | 第 $i$ 个关节的一个标量 | “第 i 轴的角度或位移” |
| $\mathbf{J}$ | 雅可比矩阵 | “关节速度到末端速度的局部映射” |
| $t,T$ | 当前时间、总时长 | “现在走到哪、总共走多久” |

角标不是装饰，也不一定表示乘方：

- 下标 `i`、`k` 通常表示序号，例如 $q_i$ 是第 $i$ 个关节；
- 下标 `start`、`goal` 表示语义，例如 $\mathbf{q}_{\mathrm{start}}$ 是起点；
- 上标 $\mathsf{T}$ 表示转置，不是坐标系；
- 上标 $-1$ 表示逆矩阵；
- 上标 $+$ 表示 Moore–Penrose 伪逆；
- 上标 $\star$ 表示期望值或目标值，不是乘法。

## 2. 坐标变换的上标和下标

本书把坐标系名称写在变换矩阵的左上角和右下角：

$$
{}^{A}\mathbf{T}_{B}
$$

读作：“坐标系 B 相对于坐标系 A 的位姿”，也可以理解为“把 B 中表示的坐标转换到 A”。

- 左上角 $A$：结果要表达在哪个参考坐标系中；
- 右下角 $B$：被描述的是哪个坐标系；
- 它们都是坐标系标签，不是指数和数组下标。

例如：

$$
{}^{\mathrm{world}}\mathbf{T}_{\mathrm{tcp}}
$$

读作“工具中心点 TCP 相对于世界坐标系的位姿”。第一次看到长变换链时，先检查相邻名称能否
首尾相消：

$$
{}^{A}\mathbf{T}_{B}\;{}^{B}\mathbf{T}_{C}
= {}^{A}\mathbf{T}_{C}
$$

中间的 $B$ 首尾相接，所以最终得到 C 相对于 A 的位姿。

## 3. 本书常用的语义下标

| 下标 | 中文含义 | 不容易误解的读法 |
|---|---|---|
| $\mathrm{current}$ | 当前值 | 机器人现在实际处于什么状态 |
| $\mathrm{target}$ 或 $\mathrm{goal}$ | 目标值 | 希望机器人最终到哪里 |
| $\mathrm{start}$ | 起点 | 规划开始时的状态 |
| $\mathrm{min},\mathrm{max}$ | 最小、最大允许值 | 约束边界 |
| $\mathrm{tcp}$ | 工具中心点 | 真正参与作业的末端点 |
| $L,R$ | 左臂、右臂 | 双臂公式中的所属机械臂 |
| $v,\omega$ | 线速度部分、角速度部分 | 雅可比矩阵的上三行和下三行 |

## 4. 常用运算符

| 符号 | 含义 | 直观解释 |
|---|---|---|
| $\lVert\mathbf{x}\rVert_2$ | 二范数 | 向量的欧氏长度 |
| $\mathbf{a}\times\mathbf{b}$ | 叉乘 | 计算旋转产生的切向运动 |
| $\sum_i$ | 对所有序号 $i$ 求和 | 把每个关节或连杆的贡献加起来 |
| $\nabla H$ | 函数 $H$ 的梯度 | 哪个方向会让代价上升最快 |
| $\det(\mathbf{R})$ | 行列式 | 旋转矩阵应等于 1 |
| $\operatorname{rank}(\mathbf{J})$ | 矩阵秩 | 当前还能独立控制多少个运动方向 |
| $\lceil x\rceil$ | 向上取整 | 不足一个采样间隔也要算一个 |

## 5. 怎样阅读一条复杂公式

以阻尼最小二乘逆运动学为例：

$$
\Delta\mathbf{q}
=
\mathbf{J}^{\mathsf{T}}
\left(\mathbf{J}\mathbf{J}^{\mathsf{T}}+\lambda^2\mathbf{I}\right)^{-1}
\mathbf{e}
$$

不要一开始逐字符阅读。按下面顺序看：

1. 左边 $\Delta\mathbf{q}$：算法要算的是“本轮关节应该改多少”；
2. 最右边 $\mathbf{e}$：输入是“当前末端离目标还差多少”；
3. $\mathbf{J}$：把末端误差映射回关节空间；
4. $\lambda^2\mathbf{I}$：在奇异位形附近增加稳定性；
5. 整体结果：用一个稳定的关节小步逼近目标。

后续章节对首次出现的复杂公式都采用“公式 → 符号含义 → 白话解释”的顺序。

## 6. 预览说明

公式使用标准 Markdown 数学块 `$$ ... $$` 和行内数学 `$ ... $`。VS Code 的内置 Markdown
预览以及支持 KaTeX/MathJax 的阅读器会排版上下标、分式和矩阵。如果使用不支持数学公式的
纯文本阅读器，公式后的中文解释仍能独立表达其含义。

命令、配置片段、终端输出和数据流图仍使用代码块；代码块不再承担数学排版。
