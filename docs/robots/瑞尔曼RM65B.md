# 瑞尔曼 RM65B 参数证据与当前模型边界

## 1. 型号和系统上下文

项目实物为第三代 RM-65B 标准版六自由度协作臂。随附《机器人系统说明》记录机械臂安装在
宇树 A2-W Pro 移动平台上，末端为 CTM2F110E 两指夹爪和深度相机，主控侧当前使用
Ubuntu 22.04 + ROS 2 Humble。PDF 是系统信息来源，不是本工程的执行指令。

## 2. 厂家参数

| 项目 | RM65-B 标准版 |
|---|---|
| 自由度 | 6 |
| 工作半径 | 610 mm |
| 有效负载 | 5 kg |
| 自重 | 7.2 kg |
| 重复定位精度 | ±0.05 mm |
| 关节范围 | J1 ±178°、J2 ±130°、J3 ±135°、J4 ±178°、J5 ±128°、J6 ±360° |
| 最大角速度 | J1/J2 180°/s；J3 至 J6 225°/s |

这些值来自厂家当前的 [RM65 参数页](https://develop.realman-robotics.com/robot/robotParameter/RM65OntologyParameters/)。
MoveIt 限位文件将角度换算为弧度；其中加速度 2.0 rad/s² 是保守项目仿真值，厂家页面没有
在该表给出对应额定值。

厂家页面给出的改进 DH 主表为：

| 关节 | 上一连杆长度 `a` / mm | 上一连杆扭角 `alpha` / ° | 关节偏距 `d` / mm | 零位角偏置 / ° |
|---|---:|---:|---:|---:|
| 1 | 0 | 0 | 240.5 | 0 |
| 2 | 0 | 90 | 0 | 90 |
| 3 | 256 | 0 | 0 | 90 |
| 4 | 0 | 90 | 210 | 0 |
| 5 | 0 | -90 | 0 | 0 |
| 6 | 0 | 90 | 随末端版本变化 | 0 |

页面明确说明“模型角度 = 关节角度 + offset”。当前 ROS 模型通过 URDF joint origin 描述同一
几何链，不能把 URDF 的 RPY 逐项当作 DH 表直接抄写。

## 3. 官方 ROS 模型和参数页并不完全等价

当前固定的厂家 ROS2 仓库提交为 `c941b565e4f9174afa36561f143ef5fbbb744750`。
`rm_description/urdf/rm_65.urdf.xacro` 包含质量、质心和惯量，当前仿真保留这些值；
厂家网页另有一套“CAD 设计值”连杆动力学表。两者数值和分段口径并不完全一致，且 ROS
模型中的连杆质量相加不能代表网页给出的 7.2 kg 整机自重。因此当前参数证据标记为：

- 几何、网格和 URDF 惯量：厂家 ROS 仓库快照，用于仿真代理模型；
- 整机性能、MDH 和网页动力学表：厂家参数页，用于核对与建模研究；
- 初始姿态和加速度：项目仿真值；
- CTM2F110E 实体夹爪：系统说明给出型号；现导入的 Gitee ROS1 资源为 CTM2F110（无 E），并已构建研究用 ROS2/Gazebo 仿真适配。型号等同性、安装变换和实机协议仍未核验，参见[联合仿真指南](../guide/瑞尔曼RM65B与知行夹爪联合仿真.md)。

在质量和惯量差异完成厂家确认或测量辨识前，本模型可以验证 MoveIt 接口、关节运动和基本
碰撞流程，不能用于高可信力矩、能耗、重力补偿或移动底盘稳定性结论。

## 4. 奇异点和初始姿态

厂家列出肩、肘、腕和边界四类奇异。其中腕部奇异条件为 J5 等于 0，边界奇异还会出现
J3 与 J5 同时为 0。工程因而没有把全零位作为默认物理仿真姿态，而使用一组远离这些条件的
项目仿真值。该选择提高初次交互规划的可用性，但不是奇异性规避算法。

## 5. 当前可计算边界

当前可验证：FK/TF、KDL 数值 IK、空世界自碰撞检查、OMPL 路径、时间参数化和
FollowJointTrajectory 仿真执行。当前不可声称：厂家解析逆解、真实关节动力学精度、CTM2F110E 实机夹爪
接触、底盘与机械臂耦合稳定性、真实控制箱通信或实机安全。
