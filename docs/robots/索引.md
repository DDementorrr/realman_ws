# 机器人参数与推导索引

本目录不把来源强度不同的数据混在一起。每份文档使用以下标签：

公式与角标统一遵循 [Markdown 数学公式与符号规范](../guide/Markdown公式规范.md)。

- A：机器人厂家公开规格/厂家维护仓库；
- B：上游 ROS/MoveIt 官方测试资源；
- C：社区 ROS-Industrial 或历史 CAD 近似；
- D：本工程为接口验证设置的仿真参数。

| 机型 | 文档 | 当前用途 | 动力学可信度 |
|---|---|---|---|
| Franka FR3 | [FR3](弗兰卡FR3.md) | 当前单臂主参考 | A，官方描述 2.9.0 |
| Fixed FR3 Duo | [FR3 Duo](弗兰卡FR3双臂.md) | 当前双臂仿真主参考 | A 几何/惯性；D position 控制接口 |
| Franka Panda | [Panda](Panda机械臂.md) | MoveIt 学习回归 | B 运动学；当前资源无惯性 |
| FANUC M-10iA test model | [Fanuc](发那科M10iA.md) | 六轴适配目标 | B/C 运动学近似；无 link 惯性 |
| PR2 | [PR2](PR2机器人.md) | 历史复合机器人资源 | C，CAD 近似且旧仿真插件 |
| RealMan RM65B | [瑞尔曼 RM65B](瑞尔曼RM65B.md) | 当前六轴实机接入目标 | A 仓库快照与网页数据存在口径差异；需辨识后用于精确动力学 |
| ChangingTek CTM2F110 | [知行两指夹爪](知行CTM2F110夹爪.md) | RM65B 末端研究用仿真代理；实体系统写 CTM2F110E | A 网页规格与 C ROS1 惯量不一致，不能用于实机动力学 |

结论先行：FR3/FR3 Duo 当前资料足以做有出处的质量/COM 重力计算。RM65B 厂家网页和
ROS 仓库都提供动力学数据，但两者口径存在差异，当前只作为仿真代理，不能据此宣称精确
补偿。Fanuc 测试模型和 Panda MoveIt resource 缺少 link inertial；正确结论是“缺参数”，
而不是补一组来历不明的数字。
