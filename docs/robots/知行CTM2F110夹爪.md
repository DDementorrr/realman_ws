# 知行 CTM2F110 夹爪：参数证据与仿真边界

## 机型识别

实体系统说明 PDF 写的是 `CTM2F110E`。本工程取得的 Gitee ROS1 仓库中，
存在 `crt_ctm2f110_gripper_visualization`，没有独立的 `CTM2F110E` 模型包。
知行官网当前产品页也以 `CTM2F110` 命名。后缀差异未确认之前，只能把本工程模型称为
**CTM2F110 研究用仿真代理**，不能据此装配或操控 CTM2F110E 实机。

## 参数证据

| 参数 | 数值 | 证据等级与含义 |
|---|---:|---|
| 最大行程 | 106 mm | A：[厂家 CTM2F110 产品页](https://en.changingtek.com/diandong/159)；不是本 URDF 的线性关节行程 |
| 最大夹持力 | 50 N | A：厂家产品页；ROS1 URDF 的 `effort=1000` 不是实机夹持力 |
| 厂家自重 | 0.75 kg | A：厂家产品页 |
| 通信 | Modbus RTU（RS485）/ IO | A：厂家产品页；当前 ROS2 包没有驱动 |
| URDF 各 link 质量和 | 0.59015 kg | C：Gitee ROS1 CTM2F110 模型展开后求和，和厂家自重不一致 |
| 主动关节范围与速度 | 0–1 rad、2 rad/s | C：Gitee ROS1 同步模型的关节限位；不是厂家开度毫米标定 |
| 主动关节加速度限值 | 2 rad/s² | D：工程仿真时间参数化所需值，未获厂家额定值 |
| RM65B 法兰安装变换 | 目前零位姿 | D：仿真占位值，不是实测 |

这组质量差异表明不能直接拿 ROS1 网格惯量推导 CTM2F110E 真实负载或重力补偿。
URDF 的关节角也不能未经几何标定就线性换算成毫米夹持宽度。

## 运动学结构

模型是一主驱动、五从动的联动两指结构。`ctm2f110_finger_joint` 为唯一规划/控制自由度；
`rightout` 和两侧 `kckle` 同向，左右 `inn` 反向。MoveIt 在 `rm65_hand` 中规划主动关节，
Gazebo Bullet Featherstone 约束联动关节，`joint_state_broadcaster` 回传实际关节位置。
这是一套 CAD/URDF 机构近似，不是厂家电机内部控制算法的推导。

使用路径、碰撞豁免与实机停止线见[RM65B 与夹爪联合仿真指南](../guide/瑞尔曼RM65B与知行夹爪联合仿真.md)。
