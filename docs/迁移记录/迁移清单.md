## 明确不迁移

- `manipulation_core` 的 DH、IK、RRT、动力学和 PID 教学实现；用户明确要求自建简要算法不迁移。
- `build/`、`install/`、`log/`、Python `__pycache__` 和临时文件。
- MoveIt/OMPL 源码 checkout、官方测试模型和教材全文。
- 当前主工作空间的 Jazzy 安装脚本及绝对路径脚本；迁移仓库另提供 Humble 版本。
- 任何 RS485、Modbus、串口或真实机械臂使能逻辑。

## 迁移完成条件

1. Ubuntu 22.04 和 ROS 2 Humble 已安装。
2. OSRF Harmonic 仓库中的 `gz-harmonic`、`ros-humble-ros-gzharmonic*` 已安装，且没有混装
   `ros-humble-ros-gz-*` 的 Fortress 包。
3. `GZ_ROS2_CONTROL_COMMIT` 已填入并构建成功。
4. 上游 RM65B commit 与 `upstream/realman_humble.repos` 一致。
5. `colcon build`、静态清单检查和两个运行时检查通过。
6. 只有在厂家型号、法兰变换、负载/碰撞参数和安全流程完成审核后，才进入实机迁移；本仓库
   不自动开启硬件驱动。
