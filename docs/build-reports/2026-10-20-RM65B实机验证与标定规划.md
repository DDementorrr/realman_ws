# 2026-10-20 RM65B 实机验证与标定规划

## 目的和当前状态

本报告给出 RM65B 从首次上电检查到受监督视觉抓放的分级验证流程。每一阶段独立记录、复核并通过 gate 后，才进入下一阶段；Gazebo 成功、MoveIt 规划成功或 RViz 显示正常都不能替代实机反馈和现场安全验收。

截至本报告日期，用户已验收当前 Gazebo 视觉抓放状态。该验收只覆盖仓库现有仿真模型、场景、传感器和软件参数。仓库没有已验证的 RM65B 实机执行后端；没有在本报告中连接或运动实机，也没有验证实际 RM65B、夹爪或相机。实机控制必须沿用现场确认的唯一厂商控制 owner，不可同时启动第二套写设备的 driver。

## 开始前需冻结的信息

由设备负责人、操作员和软件负责人共同填写并归档：

| 类别 | 必须确认的内容 |
|---|---|
| 机械臂 | 完整型号、序列号、固件、控制柜版本、安装方向、额定负载/速度限制及对应手册版本 |
| 控制链 | 当前厂商软件/驱动版本、唯一命令 owner、状态与报警接口、命令单位和坐标约定、停止/取消语义 |
| 工具 | 实际夹爪型号、通讯接口/协议、安装件、胶垫、额定行程/力、夹爪是否有可靠位置或力反馈 |
| 相机 | 型号、镜头、驱动/固件、彩色与深度分辨率/帧率、硬件同步及安装支架版本 |
| 安全 | 现场风险评估、急停位置与复位 SOP、使能装置、工作区隔离、手动/自动模式流程、断电和恢复责任人 |
| 工程 | 工控机 OS/架构、ROS 发行版、厂商工程启动方式、网络拓扑、备份和回滚办法、软件版本清单 |

型号、工具负载、安全速度、限位和停止距离以对应硬件手册及现场负责人批准值为准。本报告不推定阈值，不建议用试错方式寻找安全边界。

## 阶段与准入 gate

| Gate | 验证内容与方法 | 通过条件 / 记录 | 未通过时 |
|---|---|---|---|
| 0. 现场与安全基线 | 不发运动命令；检查底座紧固、线缆、工具/工件、急停、使能装置、隔离区、手动模式和断电恢复流程；确认一名现场操作员有停止权限 | 清单由设备负责人签字；确认安全边界、批准速度和停止测试方法；保存手册/固件/配置版本 | 停止部署，不接入工程控制链 |
| 1. 离线工程与模型审查 | 在无硬件权限/无控制网的独立环境构建；审查 URDF/SRDF、关节名/方向/范围、工具和相机安装、碰撞体、控制器接口；静态检查 launch 不启动 Gazebo、fake state 或仿真执行器 | 可复现构建；实机 observer 与仿真 launch 分离；逐项记录模型来源和待测尺寸 | 修正接口或模型，仍保持离线 |
| 2. 只读状态接入 | 仅订阅现场唯一 driver 的状态、报警、关节反馈和相机；观察多次启动/停止；对照示教器显示和厂商状态页 | 只有一个可信 JointState 来源；关节名、单位、时间戳、运动方向和报警一致；无本工程命令发布者 | 断开 observer，查明 QoS、时钟、名称或 owner 冲突 |
| 3. 静态模型/TF 核对 | 在各关节多个静止位置采反馈；RViz 展示实测 JointState；用量具/标记点对比底座、法兰、工具 TCP、夹爪和相机位置及轴向 | 每轴正方向、零位偏差和 frame 树有记录；相机盒体/工具不与实物明显错位；测量误差满足项目事先批准的建模门限 | 修正模型或标定，不能靠改 RViz 固定姿态掩盖反馈差异 |
| 4. 相机与感知 shadow | 采集图像、CameraInfo、深度和 TF；先对固定标定板做内参/畸变和深度检查，再做 eye-in-hand 外参；使用多个腕姿独立验证点位 | 静态重投影误差、深度偏差、TF/时间戳、重复定位误差均记录；目标只进入诊断/规划场景，不自动触发执行 | 检查标定、时间同步、对齐模式和遮挡；感知无效时 fail-closed |
| 5. 影子规划 | 使用实测关节状态作 start state；按量测重建底座、桌面、夹具、禁入区；在不连 controller manager/action server 的配置下生成并可视化轨迹 | 多组目标规划结果经人工审查：关节范围、奇异性、碰撞余量、速度/加速度、路径长度和规划时间有记录；执行通道不可达 | 调整模型/场景/规划参数；不允许通过计划成功直接跳到运动 |
| 6. 控制接口台架审查 | 在无机械臂运动的接口测试环境审查厂家 API/action 单位、限速、超时、取消、停止和状态回读；做命令校验、越界拒绝和断连故障注入 | 控制 owner 唯一；无效/过期/越限命令被拒绝；停止/取消语义有可观察回读；代码评审和现场书面批准完成 | 不连接实机执行接口；补足保护和诊断 |
| 7. 低风险空载基本运动 | 由持证/授权操作员控制使能；先单关节、单段、小范围、低速空载；每次只执行一个可观察动作，测试暂停/停止及报警恢复 | 逐关节方向、目标/实际差、跟随误差、运行时间、停止行为均留档；速度/行程/停止距离落在厂家和现场批准限值内 | 立即使用现场 SOP 停止，保留日志与控制柜报警，复核后从本 gate 重来 |
| 8. 运动性能与重复性 | 先空载，再经批准增加实际工具负载；重复关节空间和笛卡尔直线往返测试；用外部量具/激光跟踪仪/测量臂或固定基准靶测末端落点 | 统计每轴跟踪误差、TCP 位置/姿态误差、往返重复性、周期、停止距离、温升/报警；报告样本数、均值、最大值和标准差，按厂家与项目门限判定 | 查工具负载、安装刚度、坐标/零点、控制参数和热状态；不以单次成功判定 |
| 9. 夹爪单独验证 | 机械臂保持安全静止位；验证开合方向、端点、回读、超时/断线、软物/刚性标准块的夹持和释放；逐步使用实际物体，先称重并防坠 | 开度/位置/力回读与实测一致；断电、失联和急停后的夹持状态清楚；无拖拽、碰撞或线缆牵拉；额定负载及安全系数由负责人批准 | 退出自动流程，处理夹爪驱动或机械问题 |
| 10. 单步感知抓取 | 低速、无人员进入危险区、使用轻质有界物体；人工确认图像、目标 frame、抓取位姿和预抓取轨迹；一次只执行接近、夹持、抬升等单段 | 每段后核对实际位姿、夹爪反馈、物体位移、碰撞/报警和场景误差；能停止并安全恢复；人工确认后才执行下一段 | 停止任务，切回手动/安全位置，由现场负责人排障 |
| 11. 受监督完整任务 | 先固定工件和已测场景，再依次启用视觉、规划、执行；限制单次任务、区域、速度和操作员权限；逐轮检查抓取、搬运、放置、释放和复位 | 预先定义的成功率/精度/节拍/异常恢复门限通过有代表性的多轮样本；所有失败可追溯；软件和标定版本冻结 | 禁止无人值守与长时循环；回退到已通过的较低 gate |

## 运动性能测试方法

1. **关节跟踪与方向**：从安全位开始，由现场批准的很小单轴目标变化逐轴验证正方向、单位、目标与实测回读。记录命令/反馈时间序列、最大跟随误差、超调、稳态误差、动作时间和报警。不可借用仿真中的限位或速度值代替厂家参数。
2. **重复定位**：固定工具和测量基准，在多个可达点按同一路径正向、反向重复到位；记录末端位置和姿态。分开报告重复性与绝对准确度，测量系统的精度应优于被测门限。
3. **直线与姿态保持**：在避障区域用多个短笛卡尔段检查实际 TCP 轨迹直线度、姿态偏差和速度连续性；以外部测量设备或经过验证的固定视觉基准测量，不能只看规划轨迹动画。
4. **停止性能**：按厂家规定的测试模式和现场批准流程，分别记录暂停、正常停止、保护停止和急停响应。测量延迟和停止距离的方法、负载、速度、姿态须符合手册/风险评估；不得自行提高速度寻找边界。
5. **负载/热状态**：先空载，再由负责人确认工具、工件质量/重心和额定范围后测量；记录控制柜/电机温度、报警、周期变化及到位误差。不要用夹爪抓取成功推断机械臂负载模型正确。
6. **统计与可追溯性**：每项记录开始/结束时间、操作者、机器人和工具序列/版本、速度模式、负载、环境、样本数、原始数据文件、异常和复测结论。重复次数及容差应在测试前按厂家建议和项目风险确定。

## 必需标定与核验参数

| 参数 | 方法 | 独立验证 |
|---|---|---|
| 关节零位、方向、软限位 | 从厂商型号/固件参数读取；在安全低速小行程下对照示教器方向和实测反馈；仅由授权人员调整零位 | 多组静止姿态下对比示教器与 ROS JointState，验证范围边界由厂商定义 |
| `world/base_link` | 对照底座安装基准面、地面和工作台，用水平/垂直测量与控制柜/现场坐标记录建立变换 | 固定基准点独立量测；记录单位、轴向和右手系约定 |
| 法兰、工具安装与 TCP | 量测法兰到夹爪工具中心的刚性尺寸；多姿态 TCP pivot/calibration；记录工具版本和螺栓状态 | 让工具 TCP 接触固定尖点或基准球，多姿态检查位置不漂；比较外部测量 |
| 夹爪模型和行程 | 量测指尖、垫片厚度、开合端点、指尖中心/接触面；用夹具/量具验证方向和实际行程 | 低速多点开合读回；视觉或量具测实际间距；分辨率和回差记入误差预算 |
| 负载质量、重心和惯量 | 称量夹爪、支架、相机、线缆随动部分及工件；依厂商工具负载流程测/估重心和惯量 | 与称重/几何估算交叉核对；在厂家允许范围的姿态下检查跟踪与报警 |
| 相机内参与畸变 | 固定标定板、多距离/视角覆盖成像，标定 RGB 内参和畸变；单独检查深度尺度及对齐模式 | 多帧重投影和已知长度/距离测量；标定数据、分辨率和相机固件绑定 |
| 手眼外参 `flange/tool -> camera` | 用固定标定板在多组充分变化的腕姿下采样，按 eye-in-hand 方法求解；避免只绕单一轴运动 | 以未参与拟合的腕姿/靶点验证，比较 base 系视觉点与独立量测；报告误差和重复性 |
| 相机/机器人时间同步 | 核实图像曝光时间戳、驱动时钟、ROS 时钟和 JointState 时钟；移动时比较时间偏差 | 静止与慢速运动分别检查 TF 查询和点位误差；过期图像/TF 应被拒绝 |
| 桌面、工件与放置坐标 | 用基准平面/标定板/量具测桌面高度、边界、固定物和放置区，定义唯一参考 frame | 多个独立基准点检查坐标转换与碰撞模型；变更工位后重新测量 |
| 机器人碰撞模型 | 用准确型号模型对照实物外形；测工具、线缆、相机和固定夹具，设置可信碰撞/禁入体 | 在静态 RViz 对照并人工检查全工作区覆盖；MoveIt 无碰撞不等于现场没有危险 |

## 从零执行顺序与禁止跨越条件

- 先做 Gate 0 至 Gate 5，全程保持只读；完成后才评审控制 adapter。RViz、视觉和 MTC 仅作为 observer/shadow 运行。
- Gate 6 的控制命令验证应在不驱动实机的环境完成。进入 Gate 7 前必须有设备负责人批准、现场操作员和可达急停，并确认单一控制 owner、低速模式、限位、停止与恢复 SOP。
- Gate 7 至 Gate 9 由操作员逐项执行，避免一次接入就运行完整 demo。任何异常、通信中断、模型偏差、人员进入区域或停止响应不明确都应立即停止并回退。
- Gate 10 和 Gate 11 必须使用记录过的标定/模型版本。视觉低置信度、位姿过期、规划起点过期、夹爪状态不确定、反馈偏差超限时一律禁止下发下一段动作。
- 不跨过 gate 复用仿真阈值，不以 Gazebo 物体真值、contact/attachment topic、fake feedback 或成功的 MTC 解作为实机证据。

## Git 与工程整理边界

本次实机发布仅包含本报告及其索引/入口更新、忽略规则更新。此前未提交改动中的 Gazebo world/URDF 仿真插件、仿真控制器、接触摩擦、attachment、`pick_place_sim` 执行节点和仿真 verifier 保留在开发工作区，不进入实机规划发布分支。共享的视觉/MTC 文件虽然算法概念可复用，但当前差异耦合于本仿真坐标、模型场景和执行行为，须先拆分硬件无关接口并做独立 review，不能整文件当作实机代码上传或宣称可执行。

构建生成目录 `build/`、`install/`、`log/` 与 `.third_party/` 均为本机生成/依赖缓存，不纳入 Git；`.local_ros_*` 是本机 ROS 包提取目录，已加入忽略规则并保留供本机使用。源代码、报告和模型是否共享以明确清单提交，不批量 `git add .`。
