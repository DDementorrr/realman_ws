# 教材公式可读性整理报告

## 1. 目标

改善 `docs/textbook/` 在 Markdown 预览中的数学表达，避免用纯文本模拟上下标、矩阵和分式，
并让第一次学习机器人学的读者知道每个角标和符号的含义。

本次只调整教材表达和维护规则，不改变算法代码、配置、依赖或运行行为。

## 2. 原问题

- 公式放在 `text` 代码块中，预览只能显示 `T_0_tcp`、`q_dot` 一类 ASCII 字符串；
- 坐标系标签、关节序号、目标/当前语义和转置符号都挤在角标位置，未给出统一约定；
- 长公式缺少阅读顺序，读者容易逐字符解码而看不到输入、输出和物理含义；
- 同一个量有时写作代码标识符，有时写作数学符号，视觉层级不统一。

## 3. 完成内容

1. 新增 `docs/textbook/00-公式阅读与符号约定.md`，集中说明：
   - 标量、向量和矩阵的字体；
   - 坐标变换左上角与右下角的读法；
   - 转置、逆、伪逆和目标值上标；
   - 常见语义下标和运算符；
   - 阅读阻尼最小二乘长公式的分步方法。
2. 重排第 1–6、8、9 章的公式：
   - 将纯文本公式改为标准 Markdown 数学块；
   - 使用 `aligned`、`bmatrix` 和分式表达多行公式；
   - 对坐标变换、DH、Jacobian、DLS、RRT*、时间缩放、动力学和双臂闭链公式补充白话解释；
   - 把实验章节中的 `pi`、`epsilon`、关节向量和导数改为一致的数学写法。
3. 保留第 4、7、8、9、10 章中真正表示数据流、配置清单和终端输出的代码块。
4. 在 `AGENTS.md` 中加入教材数学表达规则，防止后续内容退回纯文本公式。

## 4. 统一约定

- 矩阵：粗体大写，例如 $\mathbf{T}$、$\mathbf{J}$；
- 向量：粗体小写，例如 $\mathbf{q}$、$\mathbf{p}$；
- 单个关节或标量：普通斜体，例如 $q_i$、$T$；
- 坐标变换：${}^{A}\mathbf{T}_{B}$ 读作“B 相对于 A 的位姿”；
- 目标量：上标 $\star$ 或语义下标 `target`；
- 复杂公式首次出现后必须说明“各符号是什么”和“整式在算什么”。

## 6. 后续维护要求

- 新公式先在 `00-公式阅读与符号约定.md` 的既有符号体系中寻找写法；
- 不为追求形式完整而堆叠角标，能用中文语义说明时优先说明；
- 一个公式承担一个主要结论，推导过长时拆成编号步骤；
- 参数名需要与代码对应时，在正文说明映射，不把 C++ 标识符直接当数学排版；
- 文档提交前至少检查数学块成对和本地链接有效。
