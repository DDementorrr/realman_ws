# MoveIt 成熟源码本地化与架构分类

日期：2026-09-09。

## 目标与实施

用户希望从成熟实现理解规划原理，并明确成熟库、自建实现和配套资产的归属。
本次将官方源码实际克隆到主工作空间，不只是添加网页链接；保留当前 Jazzy 二进制运行方式。

执行了以下克隆（从 `manipulation_ws` 看路径）：

```bash
git clone --depth 1 --branch 2.12.4 https://github.com/moveit/moveit2.git upstream/moveit2
git clone --depth 1 --branch 1.7.0 https://github.com/ompl/ompl.git upstream/ompl
```

MoveIt 提交为 `1ade0e9dcf50dbbbc3a984b995c786cf12736235`，
OMPL 提交为 `eabb4d0f825666e4553a2ec0ecb9c7a5a33637dd`。
选择依据是当前安装的上游版本，而非追随 main。浅克隆保留许可证与当前提交元数据，不含完整历史。

## 交付项

- `manipulation_ws/upstream.repos`：固定成熟算法库提交，资产 manifest 保持独立。
- `upstream/COLCON_IGNORE`：避免阅读源码加入默认构建或遮蔽运行包。
- `manipulation.code-workspace`：12 个职责分组，保留现有 ROS 包实际路径。
- [架构说明](../guide/工作空间架构.md)：所有权、运行依赖、配置资产、生成物和复现边界。
- [成熟源码导读](../guide/MoveIt源码阅读.md)：从 FR3 配置进入 KDL、PlanningScene、OMPL、时间参数化和执行管理。
- 工程纲领、AGENTS.md、工作空间 README 与教材入口已同步。
- `scripts/verify_workspace_architecture.py`：检查提交、来源、源码完整性、IDE 路径和默认包发现边界；资产修改只报告，不覆盖。
