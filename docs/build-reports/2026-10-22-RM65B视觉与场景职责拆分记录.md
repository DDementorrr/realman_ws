# 2026-10-22 RM65B 视觉与场景职责拆分记录

## 范围

按扩展方案阶段 0B，将 ArUco 目标估计和视觉目标碰撞体写入职责拆为两个 ROS 包。新增 `pick_place_perception`，保留现有 RGB-D、内参反投影、图像时间 TF、marker 中心偏移及 `/object_pose` 行为，并发布标准 `moveit_msgs/CollisionObject` 到 `/perception/collision_objects`；不再因 `plan_ready` 停止感知更新。新增 `pick_place_scene`，校验允许的对象 ID、frame、时间戳、Box 几何和尺寸，查询附着对象避免覆盖，再调用 `/apply_planning_scene`。视觉仿真编排启动两个独立节点；`pick_place_demo` 旧 console 命令保留为兼容导入。另增加仅感知、仅场景同步的独立入口。视觉模式下 `known_scene` 仍负责桌面和放置位，本次没有迁移全部场景写入者到统一场景管理节点。

RGB、深度和 CameraInfo 话题、深度编码、比例尺及 RGB/Depth 最大时间差现由参数提供。支持 `32FC1` 米制值和按配置比例换算的 `16UC1`，按 ROS Image 字节序解析；原视觉仿真编排明确配置原有话题、`32FC1`、比例尺 `1.0` 和 `0.1 s` 容差。

此修改不新增障碍物估计、工作台或执行后端，也不把仿真真值作为视觉输入。
