# 2026-10-24 RM65B 阶段 4 RGB-D 障碍几何与独立回放验收

## 本轮交付与范围

承接扩展方案阶段 3，交付阶段 4 的**静态 RGB-D 几何、未知空间保守表达、采集时刻模型过滤、独立录制回放及仿真误差评估**。没有调用 cheap-worker 或低价模型，没有连接实机。数据是 Gazebo 原生相机真实渲染后录下的消息，不能称为 RealSense 实测。

公共 `pick_place_perception` 新增 `obstacle_geometry.py`、`self_filter.py`、`depth_obstacles.py` 与 `obstacles_external.launch.py`。既有 ArUco 入口及参数保持兼容。公共包不导入仿真包，不加载 world、不读真值、不规划、不控制机器人，也不调用 `ApplyPlanningScene`。

处理链为：显式编码/单位解码 → RGB/Depth/两个 CameraInfo 配准合同 → 深度采集时间 TF → URDF 碰撞模型自过滤/单独目标屏蔽 → 工作区裁剪 → 水平支撑面 RANSAC → 欧氏连通聚类 → 已见点 AABB → 尺寸/体积/高度过滤。实现使用现有 NumPy 和已安装的 SciPy，未引入 PCL 构建链或新消息包。新增依赖均在公共包 manifest 声明。

- 解码覆盖 `16UC1` / `32FC1`、单位、字节序、行填充、截断数据及无效/超范围深度。
- 只接受显式配准的 rectified `rgb8` / 深度输入：分辨率、optical frame、内参、时间窗口一致；畸变、ROI、binning 等未支持模式明确拒绝。
- 缓存有界；颜色、深度、两个内参、完整独立关节状态和单独目标位姿按时间配对。相机和各碰撞 link 查询深度采集时刻 TF；目标按自己的采集时刻转换。不以最新 TF 代替。
- 外部模型 YAML 选择展开后的 URDF、必需 link 和显式补充相机碰撞盒；记录 URDF/模型/网格 SHA-256。Box/Sphere/Cylinder 按各自几何处理；STL 先用凸包粗筛，再用原三角面射线交点判断，不把凹形夹爪整体包成一个盒。夹指、连杆和相机各自独立。
- 目标屏蔽尺寸来自单独目标接口；仿真本轮用已知任务目标位姿，**没有声称目标也是图像估计**。显式 3 mm 屏蔽余量用于凸出的视觉标记/渲染边界；未知空间的目标内部豁免仍用未加余量的尺寸。
- RANSAC 只剔除工作区底部附近的水平支撑点，不删除场景台面，不把竖直薄墙作为主平面移除。低矮点/过小簇从已见盒中剔除后，仍由未知体素覆盖。

## 可见边界与未知区域

已见 AABB 只描述样本，`visible_bounds_complete=false`。独立可视几何发布到 `/perception/visible_obstacles`；质量、来源、时间、模型摘要、处理时延、有效深度比例、采样间距上界及丢弃尝试记录到标准 `DiagnosticArray` `/perception/obstacle_status`。

工作区划分为显式配置的体素。只有体素整个投影矩形均在视野内、深度均有效，且全部测量表面在体素最远端之后，才能判定为空闲；遮挡后方、无效像素和视野外保留为未知禁入盒。相邻 Z 体素合并，不删除任何未知单元。机器人/目标被屏蔽的像素不向其后方延伸自由射线。只有完全位于解析凸几何内部的体素才豁免；**凹形/不闭合网格均不用于未知体素内部豁免**，避免把模型空隙清空。

`/perception/collision_objects` 每次只发布一个 `depth_obstacles` compound BOX 对象，包含已见盒与未知盒；一个标准 ADD 原子替换这一静态对象。复用公共 SceneSync 的 query/apply/confirm，新增显式 `max_primitives`（默认仍为 1），确认时逐个检查所有 primitive 的尺寸和位姿，不建立新批次协议。支撑面与目标使用原 ID 和管理者，感知不发送其 REMOVE。

节点默认等待 `/perception/capture_obstacles` Trigger；服务成功只表示接受一次静态捕获，最终看观察与诊断。一次捕获后需重启才能换场景，防止未完成动态所有权协议便并发更新。无输入、坏输入、时间/TF/模型不满足、盒数量超预算或真正空快照（尚无已确认缺席协议）均不放行，也不清空旧障碍。`obstacles_ready` 使用 ROS 时间与 steady 时间双重有效期；暂停 `/clock` 仍会过期。SceneSync 的 `required_ids` 与 `input_ready_topic` 同时要求几何确认及上游有效。

这使阶段 4 有可验证的几何出口；**不等于视觉执行安全门控已完成**。误差预算、质量阈值、运行中源失效监测及后端取消确认属于阶段 5。

## 实际图像、场景事务与误差

证据根 `/tmp/realman-stage4-20261024/`。使用专用 domain/partition 和故障路径，不改默认 fault 文件。`obstacle_rgbd_sensor.launch.py` 是仿真侧独立可选俯视传感器，使用 `/stage4/camera/*` 和独立 optical frame；不修改原腕部相机。未进行额外机械臂观察运动。

录包保存原始 RGB、Depth、两个 CameraInfo、JointState、单独目标 PoseStamped，以及从实际 TF buffer 在深度/目标采集时刻取得的标准 TF 样本和 `/clock`。这是**静止场景单帧 bundle**；将 TF 展平到 output frame 便于独立回放，未伪称录制了连续腕部运动。来源、话题及文件 SHA-256 在各 bag 的 `.source.json`。真值独立保存为 `truth.sdf` / `truth-self.sdf`，仅 evaluator 分支导入仿真真值解析器，录包与公共感知不读取它。

| 用例 | 已见/未知盒 | 主要结果 |
|---|---:|---|
| 俯视 x=0.55 m，标准工作区，单薄墙 | 1 / 200 | 目标屏蔽 968 点；实际 MoveIt 全部 compound primitive 回查一致；捕获过期撤销就绪 |
| 同源实际图像，无 Gazebo 回放 | 1 / 200 | 同一公共算法；XY 全外沿差异约 **1.083 mm**，顶部误差低于 0.001 mm；已见+未知几何覆盖真值内部 **343/343** 个采样点 |
| 俯视 x=0.30 m，扩大工作区包含机器人 | 2 / 431 | 实际自过滤 **307** 点，目标屏蔽 **1004** 点；433 个 primitive 回查一致，3 台面及单独目标保留；感知过期后场景就绪撤销 |
| 扩大视野的部分表面评估 | 同上 | 可见表面误差约 **1.029 mm**；真实 40 mm 墙厚只见约 3.05 mm，完整 XY 外沿差异 **36.22 mm**；未知禁入体覆盖 **343/343** 真值内部采样点 |

第二视角的全外沿评估确实失败，原始 `evaluate-self.log` 保留；这正说明不能把单视角估计当作完整外形。后续 `--partial-view` 显式使用已见表面误差和保守覆盖验收，未放宽原完整视野的 20 mm 外沿阈值。343 点采样也不是连续几何/噪声环境的严格证明。

扩大视野还保留了基座附近一簇机器人/视觉边界残余；没有为了消除这簇残余而扩大整个夹爪屏蔽盒。未知体素也会保守地覆盖机器人网格附近区域，可能使后续规划拒绝。阶段 5 需据质量、实际任务区域和误差预算评估可用性，不能先删除这些区域来追求有解。

运行报告：`live.json`、`live-self-gate.json`、`replay.json` 及对应 `.truth-evaluation.json`。`live-self-gate.json` 同时确认 `moveit_geometry_confirmed`、`steady_expiry_confirmed`、`scene_gate_expiry_confirmed`，保留的场景 ID 在 `retained_scene_ids`。阶段 4 此处的 MoveIt fixture 同时保留原静态真值场景，**验证的是感知 compound 事务及门控，尚未证明仅凭 RGB-D 场景完成 MTC 抓放**。

## 独立回放、故障及回归

实际关闭 Gazebo/MoveIt/控制器后运行回放，进程快照为 `processes-without-gazebo.txt`。`replay.json` 保存图；独立四用例回放检查启动的只有公共感知与输入发布者，不启动相机驱动、状态发布器或执行后端。

```bash
source scripts/source_pick_place_env.sh
python3 scripts/test_stage4_geometry.py -v
ROS_DOMAIN_ID=167 ROS_LOCALHOST_ONLY=1 python3 scripts/test_scene_sync.py -v
python3 scripts/check_stage4_replay.py \
  --config /tmp/realman-stage4-20261024/perception.yaml \
  --bag /tmp/realman-stage4-20261024/rgbd-accepted-bag \
  --output-dir /tmp/rm65b-stage4-replay-new
```

输出目录必须新建。`replay-acceptance/acceptance.json` 的 4 项通过：原始录包正常输出；TF 只有未来时刻样本时不回退 latest；深度内参不匹配时拒绝；独立机器人状态缺失时拒绝。三个故障均无几何发布、`ready=false`。冻结回放时钟后 steady 过期检查通过。

几何测试 **11 项**通过，覆盖单位/字节序/stride/坏数据、配准/时间合同、水平面与薄墙、未知遮挡/失深、目标分离、夹指间隙与近旁障碍、凹网格间隙、模型缺失及盒预算。SceneSync **19 项** ROS 服务测试通过，包括新增 compound 默认拒绝/显式允许、所有 primitive 确认及非首个 primitive 的错误拒绝。新公共两包及仿真传感器入口构建通过。
