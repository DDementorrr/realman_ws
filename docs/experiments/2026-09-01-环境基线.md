# 实验报告：环境基线

## 实验目的
确认干净系统是否满足第一阶段 Level 2 仿真规划的基础条件。

## 观测结果
- Ubuntu 24.04.4 LTS，运行于 WSL2，符合目标操作系统。
- NVIDIA RTX 3050 Ti 与驱动 591.86 可见。
- Git 与 Python 已存在；CMake、ROS 2、colcon、Gazebo、RViz2、Docker 不可用。
- 无法进行 ROS 图形和 A-to-B 实验，原因是系统依赖尚未安装。

## 结论与建议
安装后基线已满足 Level 2 的软件依赖，验证脚本返回 0，Gazebo Sim 8.11.0 可执行。仍需运行一次实际 `gz sim`/RViz2 图形启动和工作空间编译实验；WSL2 GUI 显示应单独记录，不将 GUI 可见性误判为核心编译成功。

2026-09-02 资源实验：官方 `moveit_resources` `ros2` 分支已导入并构建通过。Panda 作为 API/规划学习模型可直接使用；由于 Panda 为 7 自由度，六轴验收应另选 Fanuc M-10iA、UR5/UR5e 或其他明确六轴模型。

Panda Demo 的真实 launch 检查因缺少 `controller_manager` 停止；这不是 MoveIt 资源错误，而是仿真执行链的 `ros2_control` 依赖缺失。补装后需重新运行 launch，并分别记录 GUI、控制器和规划执行结果。
