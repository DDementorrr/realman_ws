# 2026-10-19 RM65B 观察位直达与松爪接触实验

## 实验目的

验证视觉观察动作完成后，手动执行是否从当前观测位开始；并检查放置时松开夹爪后，指垫
是否继续拖动物体。

## 输入和场景

- 启动：`vision_pick_place.launch.py headless:=true use_rviz:=false auto_execute:=false wrist_camera:=true`
- 基座：`world -> base_link = [0, 0, 0.15] m`
- 物体：30 g，`0.05 x 0.07 x 0.22 m`
- 默认接触摩擦：左右指垫、物体均为 `1.2`
- 不使用 Gazebo DetachableJoint；`attachment_state` 仅作反固定附着检查

## 观测

MTC task description 的首段为：

```text
current state
open gripper
allow gripper contact
Pre-Grasp (OMPL)
pick / Approach (Cartesian)
```

没有抓取前 `Home` 阶段，说明规划输入是观察动作后的当前状态。执行节点最终单独执行
`return Home`，因此初始化姿态只出现在任务末尾。

物体位姿采样和执行状态：

| 时刻 | 结果 |
|---|---|
| 接近后 | offset `0.001 m`, tilt `0.000 rad` |
| 闭合后 | offset `0.003 m`, tilt `0.051 rad` |
| 抬升后 | object z `0.569 m`, object-tool drift `0.002 m` |
| 运输后 | object-tool drift `0.004 m` |
| 松爪前 | 放置目标误差 `0.020 m` |
| 松爪后 | offset `0.006 m`, upright tilt `0.000 rad` |
| 撤退后 | offset `0.006 m` |
| 终态 | `Pick and Place completed`, success `true`, attachment `detached` |

## 判定

三次干净执行均从观测位直接进入预抓取；其中一次松爪后偏差 `6 mm`，另一次为 `16 mm`，
均未出现继续被单指拖拽的位移趋势。摩擦从 `4.0` 降至 `1.2` 后仍完成夹持、搬运、放置和
释放。阶段 4 verifier 的基座坐标换算已修正，但接触传感器尚未稳定报告左右指垫碰撞，故
本实验不能宣称双侧接触验收通过。该结果只覆盖当前模型、物体和规划样本，仍需先修复或
补充接触观测，再进行重复性统计。
