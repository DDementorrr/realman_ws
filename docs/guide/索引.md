# Manipulation 环境说明文档库

本库服务于阅读、学习和复现。当前工程固定使用 Ubuntu 22.04、ROS 2 Humble、Gazebo Harmonic、RViz2、MoveIt 2 与 OMPL；核心适配代码通过接口与仿真后端解耦。

## 阅读顺序

本地源码已按 RM65B、CTM2F110 和 ROS 2 适配层分类：先看[工程分类与目录边界](工作空间架构.md)，
再看[RM65B 与夹爪联合仿真](瑞尔曼RM65B与知行夹爪联合仿真.md)和构建报告。

1. `工作空间架构.md`：对象目录、来源边界和运行链。
2. `瑞尔曼RM65B联合仿真.md`：RM65B 裸臂 RViz + Gazebo 接入。
3. `瑞尔曼RM65B与知行夹爪联合仿真.md`：CTM2F110 模型、SDK 和联合仿真。
4. `RM65B_PickPlace长时目标任务分类.md`：长时 Pick & Place 的阶段、模块、接口和验收矩阵。
5. `RM65B_PickPlace全流程教程.md`：有界面启动、接口验证、图像观察和 MTC/视觉原理。
6. `../build-reports/2026-09-22-RM65B与CTM2F110目录重组及ROS2-SDK构建.md`：本轮构建和运行验收。
7. `../迁移记录/迁移清单.md`：迁移范围、排除项和完成条件。
8. `../robots/索引.md`：RM65B 与 CTM2F110 来源等级及参数边界。
9. `../textbook/教材索引.md`：运动学、规划、轨迹和控制教材（历史学习资料）。

## 术语边界
当前完成的是 RM65B + CTM2F110 仿真和 CTM2F110 ROS 2 驱动的 dry-run 验收；CTM2F110E 实机串口、RM65B 实机、相机和移动平台尚未验收。历史 Panda/FR3 文档不属于本工程默认构建链。
