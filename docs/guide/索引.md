# Manipulation 环境说明文档库

本库服务于阅读、学习和复现。第一阶段固定使用 Ubuntu 24.04、ROS 2 Jazzy、Gazebo Harmonic、RViz2、MoveIt 2 Jazzy 与 OMPL；核心 C++ 逻辑通过接口与仿真后端解耦。

## 阅读顺序

本地源码已开放阅读：先看[工程分类与目录边界](工作空间架构.md)，再按
[MoveIt/OMPL 成熟源码阅读路线](MoveIt源码阅读.md)追踪当前 FR3 运行链。

1. `../双臂机器人操作项目.md`：需求、架构与阶段边界。
2. `MoveIt资源与构建.md`：上游资源、二进制包、主源码和教程的边界。
3. `学习路线.md`：MoveIt 与 Manipulation 核心知识路线。
4. `六轴与七轴对比.md`：6 轴与 7 自由度机型选择。
5. `瑞尔曼RM65B联合仿真.md`：当前实机目标的 RViz + Gazebo 首阶段接入。
   `瑞尔曼RM65B与知行夹爪联合仿真.md`：CTM2F110 ROS2 资源、末端装配与集成规划。
6. `Panda联合仿真.md`：Panda 联合仿真操作。
7. `FR3双臂联合仿真.md`：FR3 单臂/固定 Duo 的启动、交互和验收。
8. `../textbook/教材索引.md`：运动学、规划、轨迹、控制和双臂系统教材。
9. `规划算法选择.md`：OMPL planner 选择、启动参数与公平比较规则。
10. `../robots/索引.md`：各机器人参数证据和可计算边界。
11. `Markdown公式规范.md`：所有技术文档的公式、角标和自动检查规范。

## 术语边界
Level 2 已完成单臂从 A 到 B 的 IK、成熟规划、轨迹生成与控制执行；FR3 是当前主参考，Panda 是回归机型。RM65B 裸臂及 CTM2F110 研究用夹爪模型均有联合仿真回归；CTM2F110E 实机、相机和移动平台未验收。固定 FR3 Duo 已完成仿真规划/执行脚手架，但共同物体闭链、力控制、真实硬件和数字孪生接入属于后续阶段。
