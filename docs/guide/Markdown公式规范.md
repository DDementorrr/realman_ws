# Markdown 数学公式与符号规范

本规范适用于 `/home/ww/docs/` 下的教材、机器人参数说明和可复用指南。实验报告中的终端
原始输出、配置片段和日志应保持原样，不把日志内容改写成数学公式。

完整符号速查和阅读示例见 [公式阅读与符号约定](../textbook/00-公式阅读与符号约定.md)。

## 1. 数学表达与代码表达的边界

- 单个数学量使用行内数学，例如 `$q_i$`、`$\mathbf{J}$`；
- 完整等式、推导或矩阵使用独立的 `$$ ... $$` 数学块；
- 文件名、类名、参数名、topic 和命令使用反引号，例如 `DampedLeastSquaresIk`；
- 架构图、终端输出、YAML/XML 和接口清单使用带语言标识的代码块；
- 不使用 `text` 代码块模拟上下标、分式、求和或矩阵。

代码标识符与数学量同时出现时，应明确映射。例如：代码字段 `theta_offset` 对应数学量
$\theta_{\mathrm{offset},i}$，而不是把整个数学等式写进反引号。

## 2. 字体和角标

| 对象 | 统一写法 | 示例 |
|---|---|---|
| 标量 | 普通斜体 | $q_i$、$m_k$、$t$ |
| 向量 | 粗体小写 | $\mathbf{q}$、$\mathbf{p}$、$\boldsymbol{\tau}$ |
| 矩阵 | 粗体大写 | $\mathbf{T}$、$\mathbf{R}$、$\mathbf{J}$ |
| 坐标系变换 | 左上参考系、右下目标系 | ${}^{A}\mathbf{T}_{B}$ |
| 转置 | 上标正体 T | $\mathbf{J}^{\mathsf{T}}$ |
| 逆与伪逆 | 上标 $-1$ 与 $+$ | $\mathbf{T}^{-1}$、$\mathbf{J}^{+}$ |
| 目标值 | 星号或语义下标 | $\mathbf{T}^{\star}$、$\mathbf{q}_{\mathrm{goal}}$ |
| 序号 | 单字母下标 | $q_i$、$m_k$ |

坐标系标签、语义单词使用 `\mathrm{}`，例如
${}^{\mathrm{world}}\mathbf{T}_{\mathrm{tcp}}$。第一次出现的非显然角标必须紧接中文解释。

## 3. 复杂公式的呈现顺序

复杂公式统一按照以下顺序：

1. 一句话说明要计算什么；
2. 给出数学块；
3. 解释输入、输出和首次出现的符号；
4. 用一句白话说明整式的物理意义；
5. 必要时说明它与代码类、函数或配置字段的对应关系。

多行等式使用 `aligned`，矩阵使用 `bmatrix`。一个数学块只承担一个主要结论；超过三层角标
或一行过长时，优先引入有意义的中间量，不继续堆叠角标。

## 4. 推荐示例

机器人 Jacobian 的第 $i$ 列写为：

$$
\mathbf{J}_i
=
\begin{bmatrix}
\mathbf{z}_i\times(\mathbf{p}_{\mathrm{tcp}}-\mathbf{p}_i)\\
\mathbf{z}_i
\end{bmatrix}
$$

其中 $\mathbf{z}_i$ 是第 $i$ 个关节轴，$\mathbf{p}_i$ 是轴上一点，
$\mathbf{p}_{\mathrm{tcp}}$ 是工具中心点。上半部分表示线速度贡献，下半部分表示角速度贡献。

不推荐用普通字符拼接矩阵、叉乘和下标；这种写法在预览中没有清楚的视觉层级，也无法区分
坐标系标签、序号和转置。

## 5. 自动检查

修改 `/home/ww/docs/` 后运行：

```bash
/home/ww/scripts/verify_docs_math.py
```

检查器会验证：

- 展示数学块是否成对闭合；
- 数学块的花括号和 `begin/end` 环境是否匹配；
- 行内 `$...$` 是否成对；
- 教材、指南和机器人说明中是否重新出现疑似 ASCII 公式；
- Markdown 本地相对链接是否存在。

检查通过只代表文档结构有效，不代表公式在数学上正确。公式正确性仍需模型来源、手算、代码
测试和数值交叉验证。
